CYFEN LABS / ABOUT

Where curiosity meets the code.

CYFEN LABS is an independent cybersecurity learning and research project built around investigation, practical learning, and responsible security testing. Its aim is to explore how systems fail, how threats can be detected, and how security can be improved through careful analysis and continuous learning.

This website is currently a public project showcase. Interactive CTF challenges, participant accounts, scoring, and leaderboards are not enabled here. The intentionally vulnerable training challenge remains in a separate local environment.

RULES OF ENGAGEMENT

Build responsibly.

  • Test only systems you own or have explicit permission to assess.
  • Stay within the scope of each authorized lab.
  • Protect credentials, sensitive data, and challenge flags.
  • Disclose vulnerabilities responsibly and respect applicable laws.
